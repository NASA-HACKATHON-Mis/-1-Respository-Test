# 프로젝트 범위

## 프로젝트 목표

교보문고의 일반적인 온라인 서점 정보 구조와 쇼핑 흐름을 참고한 도서 판매 웹사이트 MVP를 개발한다. 사용자는 도서를 탐색·검색하고 상세정보를 확인한 후 장바구니에 담아 **테스트 주문**을 완료할 수 있어야 한다.

- 교보문고의 로고, 실제 이미지, 고유 문구나 디자인을 그대로 복제하지 않는다.
- 우선 작동하는 최소 기능을 만든다. 요청하지 않은 기능과 불필요한 방어 로직을 추가하지 않는다.
- PC와 모바일에서 동작한다.
- 외부 유료 API 없이 로컬에서 실행 및 테스트 가능해야 한다.

## 필수 기능

1. **검색:** 제목, 저자, 출판사 일부 문자열로 검색, 검색 결과 없음 안내.
2. **카테고리/정렬:** 전체 및 5개 카테고리, 가격순·최신순·인기순 정렬.
3. **상세:** 표지, 책 정보, 가격/할인율, 소개, 저자 소개, 목차, 재고, 장바구니 담기, 바로 구매.
4. **장바구니:** 추가, 수량 변경, 제거, 합계 자동 계산, 새로고침 후 유지, 재고 이상 수량 방지.
5. **테스트 주문:** 수령인·배송지 입력, 주문 확인, DB에 주문 및 항목 기록, 재고 차감, 완료 화면. 실제 결제 금지.

장바구니는 서명된 세션 쿠키에 ID·수량만 보관한다. 주문은 서버에서 sqlite3 트랜잭션으로 처리한다. 상세 규칙은 architecture.md와 contracts.md를 따른다.

## MVP에서 제외

회원가입, 로그인, 소셜 로그인, 실제 결제, 쿠폰, 포인트, 멤버십, AI 추천, 챗봇, 관리자 페이지, 리뷰 작성, 이메일/알림, 외부 서점 데이터 수집, 복잡한 대규모 운영 아키텍처. 별도 지시 없이 추가하지 않는다.

## 코딩 에이전트 준수 사항

**이것은 기능 최소화가 최우선인 MVP다.** 요구한 것만 만들고 필요 이상의 기능, 추상화, 예방 로직, 부가 서비스를 추가하지 않는다. 예외 처리는 주문 수량 및 데이터 저장 등 실제 기능에 필요한 범위에 한정한다. 화면에 정적 배열을 보여주는 것으로 DB 저장을 대체하지 않는다. 구현 후 직접 실행·검증하고 성공/실패 결과와 남은 문제를 간결하게 보고한다.
