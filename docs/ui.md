# 화면과 디자인

## 페이지 및 레이아웃

| 경로 | 역할 |
|---|---|
| `/` | 메인: 검색, 카테고리, 프로모션 배너, 베스트셀러, 신간, MD 추천 |
| `/books` | 전체 도서 목록 및 카테고리·정렬 |
| `/books/{book_id}` | 상세정보 및 장바구니/바로구매 |
| `/search` | 도서 검색 결과 |
| `/cart` | 장바구니 |
| `/checkout` | 테스트 주문 정보 입력 및 확인 |
| `/order-complete/{order_id}` | 테스트 주문 완료 |

### 메인 페이지 구조

```text
┌──────────────────────────────────────────┐
│ 로고          [도서 검색]       장바구니 │
├──────────────────────────────────────────┤
│ 전체도서  소설  자기계발  경제  인문  IT │
├──────────────────────────────────────────┤
│                메인 배너                 │
├──────────────────────────────────────────┤
│ 베스트셀러                               │
│ [표지] [표지] [표지] [표지] [표지]        │
├──────────────────────────────────────────┤
│ 새로 나온 책                             │
│ [표지] [표지] [표지] [표지] [표지]        │
├──────────────────────────────────────────┤
│ MD 추천 도서                             │
│ [표지] [표지] [표지] [표지] [표지]        │
├──────────────────────────────────────────┤
│ 고객 안내 / 서점 정보                    │
└──────────────────────────────────────────┘
```

상단에는 로고·검색창·장바구니, 다음 줄에는 카테고리 메뉴를 배치한다. 도서 카드는 표지·제목·저자·출판사·정가·판매가·할인율·샘플 평점을 표시한다. PC 한 줄 5권, 태블릿 3권, 모바일 2권을 기본으로 한다.

상세 페이지에는 도서 표지, 제목, 저자, 출판사, 평점, 가격, 재고, 수량 조절, 장바구니 담기, 바로 구매, 소개, 저자 소개, 목차, 도서 상세정보를 배치한다.

## 디자인 지침

- 밝은 배경과 명확한 타이포그래피, 포인트 컬러는 청록색 또는 짙은 파란색.
- 카드 간 여백과 표지 크기를 통일하고 제목·할인가를 시각적으로 강조한다.
- 검색과 장바구니 버튼은 모든 화면에서 찾기 쉽게 한다.
- 모바일에서는 카테고리 메뉴를 가로 스크롤하거나 간결하게 접어서 표시한다.
- 화려한 애니메이션보다 빠른 탐색과 읽기 쉬운 구성에 집중한다.


폼 경로·context는 [contracts.md](contracts.md)를 따른다. 테스트 평점/판매량과 가상 도서를 실제 데이터처럼 표시하지 않는다.
