# 프론트엔드 구현 및 검증 기록

검증일: 2026-11-08. Jinja2 템플릿과 fixture를 대상으로 확인했다.
제품 백엔드와 실제 sqlite3 구매 흐름은 아직 연결하지 않았다.

## 구현 범위

- 공통 레이아웃: 검색, 카테고리, 장바구니 수량, 푸터, 테스트 데이터 안내.
- 홈, 목록, 검색, 상세, 장바구니, checkout, 주문 완료, 오류 템플릿.
- 가상 도서 20권과 자체 제작 SVG 표지 20개.
- 정상, 빈 목록, 품절, 재고 변경, 수량 오류, 주문 입력 오류, 완료 및 HTTP 오류를 포함한 fixture 20종.
- 제품 앱과 분리된 읽기 전용 미리보기. 구매 POST는 405 안내를 반환하며 데이터를 저장하지 않는다.

## 실행

Python 3.12 이상과 Jinja2가 필요하다. 아래 명령은 저장소 루트에서 실행한다.
공통 `requirements.txt`는 백엔드 담당자가 관리하며 현재 체크아웃에는 아직 없다.
백엔드 의존성이 제공되기 전에는 별도 개발 가상환경에 `jinja2`, `pytest`를 설치한다.

```powershell
python -m pip install jinja2 pytest
python -B tools/preview_ui.py --port 8765
```

미리보기 주소: `http://127.0.0.1:8765/`.
상단의 화면 상태 선택 메뉴로 fixture를 전환한다.
검색·카테고리·정렬은 fixture 데이터로만 탐색되며 실제 DB를 조회하지 않는다.

```powershell
python -B -m pytest tests/ui -p no:cacheprovider -q
python -B tools/preview_ui.py --render-dir "$env:TEMP\nasa-ui-render"
```

## 자동 검증

- 결과: **59 passed**.
- 모든 fixture를 StrictUndefined 환경에서 렌더링했다.
- POST 폼의 경로, 필수 필드, CSRF hidden 필드와 품절 버튼 비활성화를 확인했다.
- 폼 label, 오류 참조 ID, 중복 ID, 이미지 파일과 SVG 제목을 확인했다.
- 주문 입력값 유지와 HTML escape, 필터·페이지 링크의 검색 조건 보존을 확인했다.
- 가격 합계와 홈 컬렉션 5/5/6권을 확인했다.
- 미리보기 GET 경로, POST 거부, HTML 오류 응답과 static 경로 제한을 확인했다.
- 20개 fixture의 정적 HTML 출력이 성공했다.

## 브라우저 확인

인앱 브라우저에서 홈 화면을 확인했다. 다음 수치는 스크롤바를 제외한 문서 너비다.

| 뷰포트 | 카드 열 | 문서 가로 넘침 | 이미지 로딩 오류 | 결과 |
|---|---|---|---|---|
| 1440px | 5열 | 없음 | 없음 | 홈 화면 확인 |
| 768px | 3열 | 없음 | 없음 | 홈 화면 확인 |
| 390px | 2열 | 없음 | 없음 | 홈 화면 및 가로 스크롤 카테고리 확인 |

전체 페이지에 대한 각 폭의 시각 검증, 실제 키보드 탐색과 폼 제출은 아직 완료하지 않았다.
768px 홈 배너의 장식용 영문 캡션은 줄바꿈을 추가로 다듬을 수 있다.

## 통합 시 남은 작업

- A0/A1 담당자와 공통 필드·자료형을 확인하고 실제 시드의 추가 필드 값을 fixture에 맞춘다.
- A2/A3 이후 실제 세션·DB로 장바구니 추가/수정/삭제 및 새로고침 유지를 확인한다.
- 실제 주문 저장, 재고 차감, 오류 후 입력 유지, 303 이동과 완료 화면 재조회를 확인한다.
- 수량 검증 실패 시 원래 입력값과 오류 대상 도서를 전달하는 context는 백엔드와 합의가 필요하다.
- 변경 폼 실패 시 재렌더링할 화면과 400/403/422의 HTML 오류 처리도 통합 시 확인한다.
- 전체 화면의 1440/768/390px 및 키보드 검증 후 B3/B4 인수 결과를 갱신한다.
- 실제 책 이미지 적용은 사용자가 요청한 프로젝트 완성 후의 보너스 작업이다. 현재 SVG는 유지하며 해당 GitHub 이슈는 아직 등록하지 못했다.

fixture 미리보기를 실제 주문 기능 또는 최종 인수 완료로 간주하지 않는다.
